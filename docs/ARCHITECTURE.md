# Architecture

UGS Web Hub is a static site built from plain HTML, CSS, JavaScript, and generated catalog files. The project is intentionally simple so it can run on GitHub Pages without a backend.

## Runtime Pages

- `index.html` is the main browsing hub.
- `games/` contains playable game pages.
- `library/` contains generated detail pages that add context before launching a game.
- `404.html`, `about.html`, `guides.html`, `collections.html`, `advertising.html`, `privacy.html`, and `contact.html` are static support and content pages.

## Catalog Data

- `games-data.js` exposes the raw game list.
- `games-titles.js` maps game URLs to cleaner display titles.
- `game-card-media.js` maps game URLs to card media metadata.

The hub normalizes these files in-browser into a searchable list with genre, platform, system, favorite, recent, and collection state.

## Generated Outputs

- `library/` is generated by `scripts/build-game-detail-pages.cjs`.
- `sitemap.xml` and `sitemaps/sitemap-library.xml` are generated by `generate-sitemap.js`.
- Card media metadata is built by `generate-game-card-media.js` and enrichment scripts in `scripts/`.

Generated files are committed because GitHub Pages serves the repository directly.

## Testing

Playwright runs against a small local static server from `scripts/test-server.cjs`. The suite covers:

- Hub entry, filtering, counts, themes, and collections.
- Favorites, favorite surprise, and recently played flows.
- Static support and content page navigation.
- Generated library page routing.
- Direct game page and 404 behavior.

## Deployment

The site is designed for GitHub Pages with the custom domain in `CNAME`.
